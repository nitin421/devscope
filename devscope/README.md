# DevScope — GitHub Analytics Explorer

DevScope is a React-based dashboard that helps users explore GitHub developer profiles, repository statistics, and programming language usage using the GitHub REST API.

## Features
- Search GitHub developers by username
- View profile details and statistics
- Explore repositories and programming languages
- Visualize language usage with charts
- Responsive dashboard UI

## Tech Stack
- React.js
- Vite
- Tailwind CSS
- GitHub REST API
- Recharts
- Axios
- Lucide React

## Installation

```bash
git clone https://github.com/nitin421/devscope
cd devscope
npm install
npm run dev
```
